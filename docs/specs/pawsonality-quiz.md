# 16 Pawsonalities quiz

**Status:** Phases 1 (engine and data) and 2 (admin) built 2026-10-01 · Plan and decisions: "16 Pawsonalities quiz — design and dev plan" (Claude Docs) · Source spec: quiz engine functional spec v1.0 (project doc `claude/quiz-engine-functional-spec-v1.md`) · Mock-ups: Pawtraits mock-up canvas, quiz row

## Decisions (1 Oct 2026)
- Dimensions E/I energy, S/N social, T/F training (cats: Responsive / Own Agenda), B/C boldness. 16 codes shared by dogs and cats; cats have their own type names.
- 5 questions per dimension (20 swipes), so no ties. Order is shuffled per quiz.
- No email gate: the full result is free; saving by email is optional. No offer on the result page. No Dr Warren credit.
- Server scores every result (browser score is only for the instant reveal).
- Result picture: the type's Pawsonalities theme design, in the pet's breed (made in advance for top breeds, on the spot for others).
- All content editable in Admin → Quizzes; publishing creates a new version and results keep the version they were scored on.

Dog Q6 is loaded switched off, replaced by S6. Both quizzes are published as version 1.

## Scoring (`lib/quiz/scoring.ts`)
- Right swipe scores the question's `right_pole`, left scores the other pole; majority wins per dimension.
- Ties (only if a dimension has an even number of active questions) go to the latest answer on that dimension and are flagged.
- `lockedCode()` returns the code once every letter has a majority (3 of 5) — used in phase 4 to start the breed picture early.
- Tests: `npm run test:quiz` (22 checks on the real content: all 16 types reachable for both species, flips, locking, validation).

## API
| Endpoint | Purpose |
|---|---|
| `GET /api/public/quiz/[slug]?animal=dog\|cat` | Live version: questions (with picture URL) and type names. Edge-cached 60 s |
| `POST /api/public/quiz/[slug]/results` | `{animal, petName, breedId?, answers, order?, partnerCode?, referralCode?}` → `{shareCode, code}`. Requires every question answered (409 if the version changed mid-quiz). 30 per IP per hour. Attaches the signed-in user |
| `GET /api/public/quiz-results/[code]` | Public result: pet name, species, breed, type copy from the scored version, dimension scores. No email/user/IP |

## Admin → Quizzes (phase 2)
- `/admin/quizzes`: one card per quiz and species (status, version, unpublished changes, questions, completions).
- `/admin/quizzes/[id]`:
  - **Questions:** grouped by dimension with active counts and how right swipes split between the two sides. Side editor: statement (with live "Shows as: Biscuit…" preview), dimension, what a right swipe scores (cat labels Responsive / Own Agenda), share quote, picture brief, picture upload (Cloudinary `quiz/<slug>_<animal>/<questionId>/base`), active, delete (click twice).
  - **Result types:** the 16 types; edit name, tagline, traits (one per line), signature move, owner reality, share quote, and link a Pawsonalities design (picked from any theme named "Pawsonalit…", or paste a catalogue image id).
  - **Results:** completed / shared / saved / bought for 7, 30, 90 or 365 days, results per type, latest 25.
  - **Publish version N+1:** refused while the publish check has errors (fewer than 3 active questions on a dimension, a missing or unnamed type); warnings (even question count, one-sided dimension, missing pictures or designs, no [PET_NAME]) shown but don't block. **Pause quiz / Go live** switches the public quiz off and on.
- Every edit saves to the draft and flags "Unpublished changes"; customers only see published versions.
